# Byte_Force
DevDash Repo for Team Byte_Force

## Technology Stack

### Frontend

- **Next.js** — React framework for building the web application
- **React** — Component-based UI development
- **Tailwind CSS** — Utility-first CSS framework for styling
- **TypeScript** — Type-safe JavaScript development

### Development Tools

- **Node.js** — JavaScript runtime used to run the application
- **npm** — Package manager for installing dependencies and running scripts
- **Visual Studio Code** — Code editor
- **Git and GitHub** — Version control and team collaboration

### Design and Planning

- **Canva** — Wireframes, mockups, and initial interface planning

## Project Structure

This project uses Next.js with React and Tailwind CSS. The frontend is organized into reusable React components and pages, with Tailwind CSS used for styling. Canva is used to create wireframes and plan the user interface before implementation.
